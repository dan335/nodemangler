# Packaging

Package-manager distribution. Everything here (and the two root-level dirs
below) is **generated by `scripts/update_manifests.sh`** — the `manifests` job
in `.github/workflows/release.yml` re-runs it after every release and commits
the result to main, so these files always describe the latest release without
any manual steps. Don't edit the generated files by hand; change the script.

## Layout

Two directories are forced to the repo root because the package managers only
look there:

- **`/Formula/nodemangler.rb`** — Homebrew formula. This repo doubles as the
  tap (Homebrew only scans a root-level `Formula/` dir). Users:

  ```bash
  brew tap dan335/nodemangler https://github.com/dan335/nodemangler
  brew install nodemangler
  ```

  It's a formula rather than a cask on purpose: Homebrew quarantines cask
  downloads, and Gatekeeper kills quarantined binaries that are only ad-hoc
  signed (ours are, until we pay Apple for notarization). Formula downloads
  are not quarantined, so the binaries run out of the box. Installs the GUI
  as `nodemangler` and the CLI as `mangle`; also works with Homebrew on
  Linux. If we ever ship a signed+notarized `.app`, revisit as a cask.

- **`/bucket/nodemangler.json`** — Scoop manifest. Same trick: the repo
  doubles as the bucket (Scoop only looks in a root-level `bucket/` dir).
  Users:

  ```powershell
  scoop bucket add nodemangler https://github.com/dan335/nodemangler
  scoop install nodemangler
  ```

  Installs `nodemangler` (GUI) + `mangle` (CLI) shims and a Start-menu
  shortcut. The manifest carries `checkver`/`autoupdate` metadata, but in
  practice our CI commits the bump before anyone runs `scoop update`.

The rest lives here:

- **`winget/`** — winget manifest set (version + installer + locale YAML),
  regenerated each release so it's always ready to submit. See below.
- **`appimage/`** — the `.desktop` file for the Linux AppImage; the release
  workflow assembles the AppDir (reusing the GUI's icon from
  `app/crates/mangler_gui/assets/mangler_icon.png`) and builds
  `nodemangler-vX.Y.Z-linux-x86_64.AppImage` with appimagetool.

## winget: one-time manual submission

winget packages live in Microsoft's [winget-pkgs](https://github.com/microsoft/winget-pkgs)
repo, so publishing means opening a PR there from your GitHub account — CI
can't do the first one for you. Easiest route is [komac](https://github.com/russellbanks/Komac):

```bash
brew install komac
komac submit packaging/winget --token <a GitHub PAT with public_repo scope>
```

(or copy the three YAML files into a winget-pkgs fork under
`manifests/d/DanielPhillips/NodeMangler/<version>/` and open the PR by hand).

Once the package exists, later versions can be automated from CI with
[winget-releaser](https://github.com/vedantmgoyal9/winget-releaser) plus a PAT
secret, or just re-run the `komac submit` above per release — the manifests in
`winget/` are always current.
